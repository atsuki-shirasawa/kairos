# Kairos デザイン

最終更新: 2026-10-05 / 方向: **A. 藍の時刻**（比較した 3 案のうち採用）

## 考え方

- 時間帯そのものを色にする。時刻の列は、朝の淡い空色 → 昼の白 → 夕方の琥珀 → 夜の藍へと移る。これが画面で唯一の「目立たせる要素」で、他は静かに保つ
- 作業ブロックは岩絵具のような落ち着いた色で塗る。選択・フォーカス・現在時刻には藍を使う
- カードや影は多用しない。境界は罫線で示し、ドロワーだけを面として浮かせる

| `--primary`（藍） | `#2e4c8c` | `#8da8e8` | 選択・現在時刻・フォーカス |
| `--dawn` / `--dusk` / `--night` | `#c4d0ea` / `#efc98a` / `#3a4a7c` | `#3d4f7e` / `#6b5636` / `#26335c` | 時刻列のグラデーション |
